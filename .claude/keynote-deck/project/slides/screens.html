First and last impressions

Menu

A Three.js datacenter already under attack. Loaded lazily; the game never needs it.

Takeover

The winner’s color eats the screen, the crown drops, XP counts up.

The two screens everyone sees. The menu background is a pixelated 3D aisle where AIs are already fighting, so the game feels alive before you press play. The takeover screen is plain Canvas 2D: no network, so it works offline mid-match.
