Art as text

One character, one pixel

// T = the player’s color

ai: [

'.....KKKKKK.....',

'...KKTTTTTTKK...',

'..KTTTTTTTTTTK..',

'.KTTWTTTTTTTTTK.',

'KTTTTTTTTTTTTTTK',

'KTKKKKKKKKKKKKTK',

'KTKddddWWddddKTK',

…],

// sounds are synth recipes

shoot: { wave: 'square', freq: [1400, 300], dur: 0.07 }

Rendered with smoothing off. Sounds and music are synthesized live with WebAudio.

Each sprite is an array of strings. A palette maps characters to colors, and the letter T means paint this pixel in the player’s color, which is how one sprite serves ten players. Sounds are tiny recipes: a waveform, a frequency sweep and a duration. Music is note names per step.
